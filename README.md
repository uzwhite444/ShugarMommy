# Shugar Mommy — сайт студии шугаринга

Современный одностраничный сайт с онлайн-записью: React 19 + Vite + Tailwind 4 + Supabase.

## Возможности

- **Онлайн-запись → Telegram** — клиентка выбирает зоны, мастера, дату и время; заявка сохраняется в Supabase и открывается чат с администратором (с fallback-кнопкой и копированием для in-app браузеров Instagram/Telegram).
- **Прайс + калькулятор** — отметьте зоны, скидка за комплекс считается автоматически (3+ зоны −10%, 5+ зон −15%; настраивается в `src/utils.ts`).
- **Три языка** — RU / UZ / EN, переключатель в шапке, выбор запоминается.
- **Мастера, отзывы, галерея, FAQ** — данные редактируются в `src/data.ts`; фото студии достаточно положить в `src/assets/gallery/` — подхватятся автоматически.
- **Админ-панель** — `#/admin`: вход через Supabase Auth, заявки, статусы, фильтры, статистика (визиты за сегодня, новые заявки, выручка).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3100
npm run build      # прод-сборка в dist/
```

## Настройка перед запуском в прод

1. **Контакты** — в `src/utils.ts` замените `MANAGER_TELEGRAM`, `INSTAGRAM`, `PHONE`, `ADDRESS` на реальные.
2. **Цены и услуги** — `src/data.ts` (`SERVICE_ZONES`, `MASTERS`, `REVIEWS`, `FAQ_ITEMS`).
3. **Supabase** — создайте проект и выполните скрипты по инструкции в [supabase/README.md](supabase/README.md). Там же — как назначить админа и подключить бота. Затем скопируйте `.env.example` в `.env` и заполните ключи. Публичная регистрация должна быть выключена (Authentication → Providers → Email).
4. **Деплой** — Vercel: импортируйте репозиторий, добавьте те же env-переменные, `vercel.json` уже настроен (SPA-rewrites + security headers).

Без ключей Supabase сайт работает в облегчённом режиме: запись уходит только в Telegram, админка отключена.
