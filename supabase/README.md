# База данных Shugar Mommy

Все скрипты выполняются одинаково: **Supabase → SQL Editor → вставить весь файл → Run**.
Каждый файл безопасно запускать повторно.

## Если база уже работает (обычный случай)

Ничего делать не нужно — обновления безопасности `08` и `09` уже применены.
Файлы оставлены в репозитории как история и на случай переустановки.

## Если база создаётся с нуля

Строго в этом порядке:

| № | Файл | Что делает |
|---|------|-----------|
| 1 | `setup-all.sql` | Заявки, права доступа, уведомления в Telegram, занятость слотов, отмена записи |
| 2 | `07_reminders.sql` | Напоминание клиентке за час до визита + планировщик каждые 5 минут |
| 3 | `credentials.local.sql` | Токен бота и chat_id (создайте из `credentials.example.sql`) |

Файлы `08_hardening_v3.sql` и `09_visit_duration.sql` при установке с нуля **не нужны** —
всё, что в них есть, уже входит в `setup-all.sql`.

## Ключи Telegram

Реальный токен в репозиторий не попадает: `credentials.local.sql` закрыт в `.gitignore`.
Шаблон — `credentials.example.sql`, там же написано, где взять токен и chat_id.

## Кто такой админ

Доступ к панели `#/admin` привязан к одному аккаунту Supabase по его uid —
функция `is_admin()` в начале `setup-all.sql`. Чтобы сменить админа: заведите
пользователя в **Authentication → Users**, скопируйте его UID, впишите в `is_admin()`
и выполните файл ещё раз.

Регистрация новых пользователей должна оставаться **выключенной**
(Authentication → Providers → Email → «Allow new users to sign up»). Это второй
рубеж: даже если кто-то зарегистрируется, к данным клиенток он не получит доступа.

## Обработчик бота

`functions/telegram-webhook/` — Edge Function, принимает нажатие «Старт» в боте
и привязывает Telegram клиентки к её записи, чтобы прислать напоминание.

Развёртывание:

```bash
npx supabase functions deploy telegram-webhook --project-ref <ref> --no-verify-jwt
```

Ей нужны два секрета (Project Settings → Edge Functions → Secrets):
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`. Без второго функция намеренно
не запускается — иначе её мог бы вызвать кто угодно.
